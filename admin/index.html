🚀 How to Add a New Project

  1. 1Click "Add New Project" in the sidebar and fill out all the project details.
  2. 2Add thumbnail path, demo videos, gallery images, and all relevant info.
  3. 3Click "Generate Project HTML" — the complete project page code is generated for you.
  4. 4Copy the code and save it as projects/your-project-name.html in the repo.
  5. 5Copy the Project Card snippet and paste it into index.html in the Projects section.
  6. 6Commit and push to GitHub — site goes live automatically!

└── images/ ← general images

Media Guide

How to add and reference images, videos, and documents.

📁 Where to Put Files

🖼️
Thumbnail Images
Folder: assets/projects/
Recommended: .jpg or .webp, 400×300px
/R-D/assets/projects/your-image.jpg
🎥
Demo Videos
Folder: assets/videos/
Recommended: .mp4, keep under 50MB for GitHub
/R-D/assets/videos/your-video.mp4
📄
Documents / PDFs
Folder: assets/videos/ or assets/images/
Any document type supported
/R-D/assets/videos/your-document.pdf
🖼️
General Images
Folder: assets/images/
/R-D/assets/images/your-image.png

⚡ Quick Path Reference

File Type Put File In Use Path
Project thumbnailassets/projects//R-D/assets/projects/name.jpg
Demo videoassets/videos//R-D/assets/videos/name.mp4
Gallery imageassets/images//R-D/assets/images/name.png
Document/PDFassets/videos//R-D/assets/videos/name.pdf

🚀 Deploy to Live Site

After adding files and generating HTML, run these commands in your terminal:

git add .
git commit -m "Add new project: [project name]"
git push origin main

GitHub Pages will auto-deploy in ~1-2 minutes.
